# CLAUDE.md

Le istruzioni per lavorare su questo repository stanno in **[AGENTS.md](AGENTS.md)**.

Leggile prima di iniziare, in particolare:

- mai eseguire `flutter test`, mai fare `git push` senza richiesta esplicita;
- messaggi di commit in italiano (titolo + elenco puntato senza righe vuote);
- `kotlin.incremental=false` in `android/gradle.properties` deve restare;
- tutto il codice dell'app vive in `lib/main.dart`.
